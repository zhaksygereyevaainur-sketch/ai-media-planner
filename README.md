# AI Медиапланировщик

Интерактивный кликабельный прототип рабочего места рекламного менеджера медиакомпании — без бэкенда, на демо-данных. Полное описание требований — в [PRD.md](PRD.md).

**Живая демо-версия:** https://zhaksygereyevaainur-sketch.github.io/ai-media-planner/

Один расчёт — единственный источник данных для коммерческого предложения, черновика договора и делового письма клиенту.

## Блоки

- **Клиенты** — карточки, статусы, история договорённостей
- **Прайс-листы** — каталог рекламных продуктов по категориям
- **Расчёты** — конструктор сметы: позиции, скидки, НДС, итог
- **Коммерческие предложения** — генерация КП на основе расчёта
- **Договоры** — черновик договора (DRAFT) с пометкой о проверке юриста
- **Деловые письма** — сопроводительные письма, напоминания, благодарности

Тексты (вводные абзацы КП, разделы договора, письма) собираются локальным генератором на основе шаблонов компании — без внешних API и без бэкенда.

## Технологии

Чистый HTML/CSS/JavaScript без сборки и зависимостей. Состояние хранится в `localStorage` браузера.

## Запуск локально

```powershell
powershell -File serve.ps1
```

Затем открыть `http://localhost:8080` в браузере.

Файл `index.html` также можно открыть напрямую, но некоторые браузеры ограничивают выполнение скриптов для `file://`, поэтому предпочтителен локальный сервер.
